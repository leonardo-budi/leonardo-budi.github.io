The agreed next project is an **audit of Leo's OVO, DDT, and Nobu work**, run as its own separate effort, to determine whether authentic, showable evidence exists. The audit looks for: the component library or token system itself; contribution or governance rules Leo set; documentation he authored; evidence of adoption and what changed after; and which decisions were genuinely his versus the team's.

Crucial constraint: the audit decides the outcome, not a predetermined wish. Possible results:
- Enough for a **full Design Systems case study** (Rail template).
- Enough for a **lighter Systems Gallery** (Gallery template).
- **Not enough to show** without breaching confidentiality, in which case the honest move is to dial the systems claims on the homepage down to match demonstrable evidence, so the testimonials stop pointing at an absence.

Same rules as the rest of the project: truthful over impressive, no invented narrative, modest when unsure. The audit will go faster if Leo first gathers source material (Figma files, old docs, screenshots) from those roles.
